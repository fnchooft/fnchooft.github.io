OTP 29 shipped several features that have been on the community wish-list for years. The demo module below exercises each one in a `run_all/0` function you can call directly from the shell. Most features work with a standard `erlc` compile; two experimental ones need explicit feature flags.

Reference: [OTP 29 release notes](https://www.erlang.org/news/186)

## Feature map

| Function | Feature | Notes |
|---|---|---|
| `demo_is_integer_guard/0` | New `is_integer/3` BIF | Available in RC1 |
| `demo_multi_valued_comprehensions/0` | Multi-valued list/map comprehensions (EEP-78) | RC1; `compr_assign` needs a flag |
| `demo_rand_shuffle/0` | `rand:shuffle/1` and `rand:shuffle_s/2` | RC1 |
| `demo_io_ansi/0` | `io_ansi` VT/ANSI terminal sequences | RC2 |
| `demo_compiler_warnings_guide/0` | 4 new default compiler warnings | RC1 |

SSH security defaults (post-quantum `mlkem768x25519-sha256`, daemon shell/exec/SFTP disabled by default) and native records (EEP-79) are configuration and flag changes rather than new API calls — they are documented in inline comments in the source.

## Key caveats

**Native records (EEP-79)** are experimental. They require `-feature(native_records, enable)` at the top of the module and the `-enable-feature native_records` compiler flag. Without both, the module compiles as if the feature does not exist and the record syntax falls back to the regular record implementation.

**`compr_assign`** — variable binding in comprehensions — similarly needs `-enable-feature compr_assign`. This lets you write `[X = f(I) || I <- List]` and have `X` bound in the output expression, which was not possible before.

**`io_ansi`** output depends on the terminal. In a plain pipe it prints raw escape codes. Redirect to a file and you will see the codes rather than colours.

## Installation with kerl

`kerl` is the recommended way to manage multiple Erlang versions in parallel. To build OTP 29:

```bash
kerl build 29.0-rc3
kerl install 29.0-rc3 /home/fnchooft/erlang/29.0-rc3
. /home/fnchooft/erlang/29.0-rc3/activate
```

## Compiling and running

Standard compile covers most features:

```bash
erlc otp29_new_features.erl
```

Experimental features need flags:

```bash
erlc -enable-feature native_records \
     -enable-feature compr_assign \
     otp29_new_features.erl
```

Run all demos:

```bash
erl -noshell -eval "otp29_new_features:run_all()" -s init stop
```
