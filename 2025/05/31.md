GSL — the Generator Scripting Language, originally by Pieter Hintjens and the iMatix team — is a small, opinionated code generator. You describe your data in an XML model file and write a template that walks the model and emits whatever text you want: C structs, SQL schemas, protocol buffers, documentation. The generator is a single binary. There are no dependencies, no runtime, no build step on the target.

I wanted to test whether Gemini could learn GSL from its README alone and produce a working generator without iteration. The assignment: generate C structs from a simple entity model.

## The model file

The first step is an XML file that describes the entities. I asked Gemini to produce `entities.xml` with typical fields. It got the structure right immediately:

The template iterates over every `<entity>` element and its `<field>` children. The GSL `.` operator dereferences a child element; `$(name)` interpolates a value. The only tricky rule: generated lines that begin with a `.` must be escaped — Gemini got tripped up on this once and needed a correction.

`main.c` is the hand-written harness. `Person.h` and `Person.c` are entirely machine-generated from the template and the model — no human edits. The Makefile drives `gsl entities.xml` before compilation.

## Conclusions

Gemini produced a working generator in roughly three exchanges. It understood the GSL loop and output syntax from the README alone, which is not a small document. The areas where it needed correction:

1. **Leading-dot escaping.** Lines in the generated C that start with `.` (unlikely but possible in some templates) must be escaped as `..`. Gemini forgot this in one template and needed a nudge.
2. **Memory management.** The generated C uses `malloc` without `free`. A human C developer would add cleanup; the template could be extended to generate it, but that is a second exercise.

The approach generalises. The same entity model could drive templates for Go structs, Python dataclasses, or SQL `CREATE TABLE` statements. You change the template, not the model.
